# Laço Vivo

Website editorial de conscientização e educação sobre câncer de mama. Projeto em `pt-BR`, planejado com Vite, React, TypeScript e React Router v7.

## Desenvolvimento

```powershell
npm.cmd install
npm.cmd run dev
```

## Verificação e build

```powershell
npm.cmd run typecheck
npm.cmd run build
```

As decisões de conteúdo, identidade visual, acessibilidade e produção de mídia estão documentadas em `docs/`. A implementação atual contém a estrutura de navegação e layouts iniciais; os assets finais e o documentário ainda não foram produzidos.
