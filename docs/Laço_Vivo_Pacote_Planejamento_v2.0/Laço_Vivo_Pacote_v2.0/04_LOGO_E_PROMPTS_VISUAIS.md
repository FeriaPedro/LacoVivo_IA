# LAÇO VIVO — BRIEFING DE LOGO E PROMPTS VISUAIS

## 1. Direção final da marca

**Nome:** laço vivo  
**Slogan:** Informação que acolhe. Prevenção que transforma.  
**Logo:** laço de conscientização verdadeiro, com desenho original, soft e elegante.  
**Cores:** rosa suave `#E8AAB8` e champagne `#D8C5AC`, com wordmark off-white `#F8F5F1` em fundo `#171519`.  
**Fonte:** Nunito Sans 600.

A logo deve ser adulta, delicada e reconhecível. Não usar laço infantil, coração, estetoscópio, cruz médica, mãos em oração, borboleta ou ícone stock.

## 2. Prompt principal para gerar referência de logo (English)

> Create an original, premium breast-cancer-awareness ribbon symbol for a Brazilian educational brand named “Laço Vivo”. Generate the symbol only — absolutely no lettering, no words, no initials, no slogan, no mockup, no watermark. Design a recognizable awareness ribbon made from one elegant flowing band, with soft rounded curves, balanced proportions, a graceful central crossing and two clean ribbon tails. The silhouette must feel calm, human, refined, contemporary and memorable, not childish, not generic, not overly decorative. Main color soft blush pink #E8AAB8, with only a tiny champagne accent #D8C5AC if it improves the design. Flat refined vector identity style, clean edges, minimal shapes, high legibility at small sizes, centered composition, transparent background, no shadows, no glow, no gradients, no extra objects. The mark must remain clear as a small favicon and work on a deep charcoal background.

## 3. Instrução de vetorização/wordmark para Codex

After the image-generation reference is approved, create a clean, original SVG version from scratch using simple Bézier paths. Do not embed a low-resolution raster inside an SVG and do not auto-trace jagged edges. Keep the mark readable at 24 px, 32 px and 64 px. Create:
- `logo-horizontal.svg`: ribbon + “laço vivo” wordmark (the wordmark should be real text in Nunito Sans 600 where practical, or a clean editable vector only if necessary).
- `logo-mark.svg`: isolated ribbon symbol.
- `favicon.svg`: simplified mark, optimized for tiny display.
- transparent PNG exports only if needed.
The mark must have a monochrome variant and remain identifiable in one color. Do not add the slogan inside the symbol.

If the Codex image-generation skill is unavailable, do not claim image generation succeeded. Use the written prompt as a handoff for a supported image tool, then continue with an SVG implementation only after the reference is supplied/approved.

## 11. Regras comuns para todos os assets

- Não gerar texto, letras, números, logos de terceiros ou rótulos dentro de imagem.
- Não usar fotos de pacientes reais nem retratos que pareçam depoimentos documentais sem consentimento.
- Não gerar feridas, lesões gráficas ou cenas médicas invasivas.
- Não gerar mamografias/ressonâncias/raios-X falsos para parecerem exames reais.
- Padronizar iluminação, paleta e acabamento entre assets.
- Guardar prompts e nomes de arquivos em `public/assets/prompts/` ou `docs/asset-prompts/`.
- Usar nomes descritivos: `logo-ribbon-reference.png`, `home-embrace-symbol.png`, `documentary-poster.png`, `breast-anatomy-schematic.png`, `symptom-icons-*.png`, `prevention-habits-*.png`, `mammography-machine-illustration.png`, `care-network-illustration.png`.
- Gerar alt text no código, não dentro da imagem.
