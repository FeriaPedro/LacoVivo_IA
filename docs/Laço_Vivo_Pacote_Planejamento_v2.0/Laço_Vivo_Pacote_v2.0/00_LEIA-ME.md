# LAÇO VIVO — PACOTE DE PLANEJAMENTO v2.0

**Data de referência:** 30/10/2026  
**Idioma do site:** português brasileiro (pt-BR)  
**Status:** planejamento editorial, visual e técnico consolidado; implementação no VS Code ainda não iniciada.

## O que há neste pacote

1. `01_DOCUMENTO_MESTRE_v2.0.md` — referência central e decisões consolidadas.
2. `02_CONTEUDO_DAS_CINCO_PAGINAS.md` — primeira versão revisada dos textos das cinco páginas.
3. `03_DESIGN_SYSTEM_E_LAYOUTS.md` — paleta, tipografia, componentes e layout de cada página.
4. `04_LOGO_E_PROMPTS_VISUAIS.md` — briefing da marca e prompts de assets para Codex/GPT Image.
5. `05_VIDEO_DOCUMENTARIO.md` — roteiro, storyboard, prompts de cenas e requisitos de acessibilidade.
6. `06_CODEX_MASTER_PROMPT.md` — prompt mestre em inglês para implementar o site no Codex.
7. `07_CODEX_EXECUTION_CHECKLIST.md` — sequência de execução, validação e critérios de aceite.

## Como usar

- Leia primeiro o Documento Mestre e o Design System.
- Cole o prompt mestre no Codex com a pasta do projeto aberta no VS Code.
- Peça ao Codex para primeiro auditar o workspace e apresentar o plano; só depois permita que ele crie/edite os arquivos.
- Faça a geração dos assets por IA quando o Codex verificar que a skill de geração de imagens está disponível. Se não estiver, ele deve informar a limitação e entregar os prompts prontos, sem fingir que gerou arquivos.
- Para o vídeo, o Codex pode preparar a montagem e a integração; a geração dos clipes depende de um modelo de vídeo específico e de acesso/autorização à ferramenta.
- Não publicar o conteúdo de saúde sem revisão final do professor e, idealmente, de um profissional/serviço de saúde. As fontes oficiais e a data de verificação devem aparecer no site.

## Limites importantes

Este pacote não é um site implementado, não contém imagens geradas nem um vídeo final. É o material de planejamento para o Codex executar o desenvolvimento. O Codex não deve inventar que concluiu geração de mídia sem salvar e verificar os arquivos reais.
